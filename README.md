# Stud Stephan

Meine Klemmbaustein-Sammlung als Vitrine: Minifiguren (offiziell, modifiziert, custom), Sets, Sonderteile, MOC-Dioramen, Wunschliste und Marktwerte. Persönliche App für einen Nutzer.

Online: https://stephan-pro.github.io/stud-stephan/

## Loslegen

```
npm run setup
npm run check
npm run dev
```

- `npm run setup` – Pakete und Test-Browser installieren (einmal).
- `npm run check` – alles prüfen: Stil, Typen, Tests, Build, Abläufe im Browser.
- `npm run dev` – App lokal starten; `npm run demo` mit Beispieldaten.
